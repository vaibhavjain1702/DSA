# DSA

My journey through understanding Data Structures and Algorithms, starting from C++ fundamentals.

## Contents

| File | Topic |
|---|---|
| `First.cpp` | Hello World, `cout`, `endl` and newlines |
| `data.cpp` | Variables and data types (`int`, `char`, `float`, `bool`) |
| `second.cpp` | Input with `cin`, sum of two numbers, typecasting and data loss (`int` to `char`) |
| `if_else.cpp` | Conditionals: `if` / `else`, nested conditions |
| `loop.cpp` | Loops: counting, printing n natural numbers, squares |
| `for.cpp` | `for` loops: ranges, characters, countdown, custom steps |
| `pattern.cpp` | Pattern printing with nested loops (squares of stars and numbers) |
| `pattern2.cpp` | Triangle patterns (stars, increasing numbers) |
| `pattern3.cpp` | Right-aligned (space + star/number) triangle patterns |
| `pattern4.cpp` | Pyramid / palindromic number patterns |

Many experiments are kept as commented-out blocks, separated by `// ----` lines.

## Build and run

```bash
g++ First.cpp -o First
./First
```

Compiled binaries are git-ignored.
